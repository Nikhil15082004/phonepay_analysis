# PhonePe Transaction Analysis

This is a **Power BI project** where I analyzed PhonePe transaction data to understand transaction trends, customer behavior, services, and payment status.

## Tools Used

* Power BI
* Excel
* DAX

## Dataset

The dataset contains information about:

* Users
* Transactions
* Transaction amount
* Services
* Payment status
* Age
* Transaction date

The dataset contains around **107K users and 300K transactions**.

## What I Analyzed

In this project, I analyzed:

* Total transactions
* Total transaction value
* Unique users
* Monthly transaction trends
* Transaction value by service
* Transaction value by age group
* Top 5 users by transaction value
* Weekday vs weekend transactions
* Payment status

## Key Insights

* Weekday transactions are higher than weekend transactions.
* Insurance has the highest transaction value among the shown services.
* Gen X and Millennials contribute a large part of the transaction value.
* Transaction activity changes across different months.
* The dashboard shows the top users based on transaction value.

## Dashboard

The dashboard contains 3 pages:

1. **Payment Insights**
2. **Service Type Analysis**
3. **Age Segment Analysis**
